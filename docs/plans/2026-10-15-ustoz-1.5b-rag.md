# Ustoz v2 — Qwen2.5-1.5B + RAG (LangChain, LangGraph, LangSmith, Qdrant) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the Post_Training project into a measured, end-to-end LLM system: a post-trained Qwen2.5-1.5B ("Ustoz") that answers LLM-course questions in Uzbek from the course materials. Retrieval runs on a Qdrant hybrid index, orchestration on a LangGraph corrective-RAG graph, and monitoring on LangSmith. Every pipeline and every model (Ustoz, Qwen-Instruct, Groq, OpenAI, Claude) is compared on the same test set.

**Architecture:** The repo keeps its two layers. The **model layer** (`sft/`, `sft_v2/`, `eval/`) trains and scores adapters on the 68-question behaviour test. The new **system layer** (`rag/`, `eval_rag/`) is a Python package. It indexes course materials into Qdrant (dense `bge-m3` + sparse BM25), retrieves with a cross-encoder reranker and parent-section expansion, and answers through a LangGraph graph. The graph routes the question, retrieves, grades the documents, rewrites the query, generates with citations, and checks groundedness. Every LLM is called through one LangChain registry, so any generator can be swapped by name. LangSmith traces every run and stores the RAG test set and experiments; result tables are also written to `results/` in git.

**Tech Stack:** Python 3.12 (local venv) · PyTorch / Transformers / PEFT / bitsandbytes (Kaggle GPU) · llama.cpp GGUF export + Ollama · LangChain 1.x (`init_chat_model`) · LangGraph · LangSmith · Qdrant (`qdrant-client` local mode, `langchain-qdrant` hybrid) · `BAAI/bge-m3` embeddings · `BAAI/bge-reranker-v2-m3` · FastEmbed BM25 · pymupdf4llm · FastAPI · pytest.

**Spec:** `MODEL_SPEC.md` (how Ustoz must behave: language, answer style, tasks, limits) plus the goals in this plan. Answers produced by the RAG system follow `MODEL_SPEC.md` exactly like the fine-tuned model does.

## Global Constraints

- Python **3.12** in `.venv` for everything under `rag/`, `eval_rag/`, `tests/` (`py -3.12 -m venv .venv`). Your global Python 3.14 has no torch wheels you can rely on; do not use it for this project.
- Training stays on **Kaggle GPU**. The laptop (i7-1165G7, 16 GB RAM, no NVIDIA GPU) only runs Ollama inference, embeddings, and the reranker.
- `MODEL_SPEC.md` is the source of truth for answer behaviour: Uzbek (Latin) by default, English when asked in English, no mixing, English technical terms kept, 1–5 sentences, "Bilmayman" when unknown, refuse harmful requests and exam cheating.
- Claude model IDs: `claude-opus-5-5` (default). `claude-haiku-5-5` is the cheap option, used only where you choose it in `.env`. **Never pass `temperature` / `top_p` / `top_k` to Claude**: current Claude models reject sampling parameters with HTTP 400. `rag/llms.py` strips them.
- OpenAI and Groq model IDs are **your choice** from each provider's current model list, set in `.env` as `OPENAI_MODEL` and `GROQ_MODEL`. Nothing in code hard-codes them.
- Secrets live only in `.env` (gitignored). `.env.example` is committed with every key name and no values.
- **Test-set separation:** the 68-question set is never changed to make a model pass. RAG test questions come only from `eval_files` in `eval_rag/split.json` and are never used in any training data (Task 15 trains only on `train_files`).
- Code comments, docstrings and CLI messages in **Uzbek**, matching the existing scripts; READMEs in **English**, matching the existing READMEs.
- Every RAG run is traced to LangSmith project `ustoz-rag` with metadata `{"pipeline", "generator", "model_id"}`.
- Course materials you cannot publish go in `rag/corpus/private/` (gitignored); only `rag/corpus/public/` is committed.

## Review Focus

1. **Uzbek apostrophe variants** (`o‘`, `oʻ`, `o'`, `` o` ``) in documents vs. queries. The same word must match in BM25 and dense search. `normalize()` is applied at ingest *and* at query time. Pinned by `test_query_apostrophe_variants_match` in Task 8.
2. **Question not covered by the course** ("Kim 2018 yilgi jahon chempionatida g'olib bo'lgan?"). The graph must answer "Bilmayman" ("I don't know" for English questions), not invent an answer. Pinned by `test_no_relevant_docs_after_rewrites_says_bilmayman` in Task 10.
3. **English question over an Uzbek corpus.** The answer must be in English. Pinned by `test_unknown_answer_matches_question_language` in Task 10 and the `language_ok` evaluator in Task 13.
4. **Missing API key or unset model ID.** The app must fail at startup with a message naming the missing `.env` variable, not with a stack trace mid-graph. Pinned by `test_missing_key_names_env_var` in Task 5.
5. **Grader keeps rejecting every document.** The rewrite loop must stop after `max_rewrites` (2) and end at "Bilmayman". Pinned by `test_rewrite_loop_stops` in Task 10.

```python
"""Natija faylidagi o'tmagan javoblarni vazifa bo'yicha chiqaradi.

Ishga tushirish:  python eval/inspect_failures.py sft-lora-1.5b
                  python eval/inspect_failures.py sft-lora-1.5b --task explain
"""
import argparse
import json
from pathlib import Path

HERE = Path(__file__).parent


def main():
    p = argparse.ArgumentParser()
    p.add_argument("name", help="eval/results/<name>.json")
    p.add_argument("--task")
    args = p.parse_args()

    rows = json.loads((HERE / "results" / f"{args.name}.json").read_text(encoding="utf-8"))
    failed = [r for r in rows if not r["auto_pass"] and (not args.task or r["task"] == args.task)]
    for r in failed:
        print(f"--- {r['id']} [{r['task']}]")
        print("Savol:  ", r["messages"][0]["content"])
        print("Javob:  ", r["messages"][1]["content"])
        print("Namuna: ", r["reference"], "\n")
    print(f"{len(failed)} ta o'tmagan javob")


if __name__ == "__main__":
    main()
```

```python
"""LoRA adapterni base modelga qo'shib, bitta to'liq model sifatida saqlaydi (GGUF'ga o'tkazish uchun).

Ishga tushirish:  python serving/merge_adapter.py --adapter sft-lora-1.5b
"""
import argparse
from pathlib import Path

import torch
from peft import PeftModel
from transformers import AutoModelForCausalLM, AutoTokenizer

ROOT = Path(__file__).resolve().parent.parent


def main():
    p = argparse.ArgumentParser()
    p.add_argument("--base", default="Qwen2.5-1.5B")
    p.add_argument("--adapter", default="sft-lora-1.5b", help="Task 1 dagi eng yaxshi adapter")
    p.add_argument("--out", default="serving/ustoz-1.5b-merged")
    args = p.parse_args()

    tok = AutoTokenizer.from_pretrained(ROOT / args.base)
    base = AutoModelForCausalLM.from_pretrained(ROOT / args.base, dtype=torch.float16)
    model = PeftModel.from_pretrained(base, ROOT / "chat_ui" / "adapters" / args.adapter).merge_and_unload()

    tok.save_pretrained(ROOT / args.out)
    print("Saqlandi:", ROOT / args.out)


if __name__ == "__main__":
    main()
```

- [ ] **Step 6: Write `serving/parity_check.py`**

```python
"""Ollama'dagi ustoz-1.5b transformers bilan bir xil javob beradimi: eval natijalari bilan solishtiradi.

Ishga tushirish:  python serving/parity_check.py --results sft-lora-1.5b --n 10
"""
import argparse
import json
import sys
import urllib.request
from pathlib import Path

ROOT = Path(__file__).resolve().parent.parent
sys.path.insert(0, str(ROOT / "eval"))
from run_eval import auto_check  # noqa: E402


def ollama_chat(model, question):
    body = json.dumps({"model": model, "stream": False, "options": {"temperature": 0},
                       "messages": [{"role": "user", "content": question}]}).encode()
    req = urllib.request.Request("http://localhost:11434/api/chat", body, {"Content-Type": "application/json"})
    with urllib.request.urlopen(req, timeout=300) as r:
        return json.loads(r.read())["message"]["content"].strip()


def main():
    p = argparse.ArgumentParser()
    p.add_argument("--results", default="sft-lora-1.5b")
    p.add_argument("--model", default="ustoz-1.5b")
    p.add_argument("--n", type=int, default=10)
    args = p.parse_args()

    items = {i["id"]: i for i in json.loads((ROOT / "eval" / "eval_set.json").read_text(encoding="utf-8"))}
    rows = json.loads((ROOT / "eval" / "results" / f"{args.results}.json").read_text(encoding="utf-8"))[:args.n]
    same = 0
    for r in rows:
        answer = ollama_chat(args.model, r["messages"][0]["content"])
        ok = auto_check(items[r["id"]], answer)
        same += ok == r["auto_pass"]
        print(f"{r['id']}: transformers={r['auto_pass']} ollama={ok}")
    print(f"Mos keldi: {same}/{len(rows)}")
    sys.exit(0 if same >= len(rows) - 1 else 1)


if __name__ == "__main__":
    main()
```

```python
"""Matnni solishtirishga tayyorlash va savol tilini aniqlash."""
import re

APOSTROPHES = str.maketrans({c: "'" for c in "‘’ʻʼ`"})   # eval/run_eval.py dagi bilan bir xil

UZ_WORDS = {"va", "nima", "qanday", "uchun", "bilan", "bu", "emas", "nechta", "haqida", "ham", "yoki",
            "agar", "menga", "qil", "ber", "nega", "qachon", "qaysi", "kerak", "bo'ladi", "ishlaydi"}
EN_WORDS = {"the", "is", "what", "how", "and", "of", "to", "in", "a", "for", "with", "does", "why",
            "are", "do", "can", "which", "when", "it", "we", "need"}


def normalize(text: str) -> str:
    return text.translate(APOSTROPHES)


def detect_lang(text: str) -> str:
    words = re.findall(r"[a-z']+", normalize(text).lower())
    uz = sum(w in UZ_WORDS for w in words)
    en = sum(w in EN_WORDS for w in words)
    return "en" if en > uz else "uz"
```

```python
"""Bitta nom -> LangChain chat model. Generator ham, boshqaruvchi (router/grader) ham shu yerdan olinadi."""
import os

from langchain.chat_models import init_chat_model

REGISTRY = {
    "claude":             {"provider": "anthropic", "model": "claude-opus-5-5", "key": "ANTHROPIC_API_KEY"},
    "claude-haiku":       {"provider": "anthropic", "model": "claude-haiku-5-5", "key": "ANTHROPIC_API_KEY"},
    "openai":             {"provider": "openai", "model_env": "OPENAI_MODEL", "key": "OPENAI_API_KEY"},
    "groq":               {"provider": "groq", "model_env": "GROQ_MODEL", "key": "GROQ_API_KEY"},
    "ustoz-1.5b":         {"provider": "ollama", "model": "ustoz-1.5b", "key": None},
    "qwen-1.5b-instruct": {"provider": "ollama", "model": "qwen2.5:1.5b-instruct", "key": None},
}
SAMPLING = ("temperature", "top_p", "top_k")


class ModelConfigError(RuntimeError):
    pass


def resolve(name):
    """-> (provider, model_id). .env da biror narsa yetishmasa, qaysi o'zgaruvchi ekanini aytadi."""
    if name not in REGISTRY:
        raise ModelConfigError(f"Noma'lum model: {name}. Mavjudlari: {', '.join(REGISTRY)}")
    entry = REGISTRY[name]
    if entry["key"] and not os.getenv(entry["key"]):
        raise ModelConfigError(f"'{name}' uchun .env da {entry['key']} yo'q")
    model = entry.get("model") or os.getenv(entry["model_env"])
    if not model:
        raise ModelConfigError(f"'{name}' uchun .env da {entry['model_env']} yo'q")
    return entry["provider"], model


def get_llm(name, **kwargs):
    provider, model = resolve(name)
    if provider == "anthropic":
        for k in SAMPLING:          # Claude sampling parametrlarini qabul qilmaydi (HTTP 400)
            kwargs.pop(k, None)
        kwargs.setdefault("max_tokens", 4000)   # thinking ham shu limitga kiradi
    else:
        kwargs.setdefault("temperature", 0)
    return init_chat_model(model, model_provider=provider, **kwargs)


def text_of(message):
    """AIMessage -> faqat matn (thinking va boshqa bloklarsiz)."""
    content = message.content
    if isinstance(content, str):
        return content
    return "".join(b.get("text", "") for b in content if isinstance(b, dict) and b.get("type") == "text")
```

```python
"""Kurs materiallari -> parent bo'limlar (sarlavha bo'yicha) va qidiruv uchun kichik child chunklar.

Qidiruv kichik chunk ustida aniqroq; modelga esa butun bo'lim (parent) beriladi.
"""
import hashlib
import json
from pathlib import Path

from langchain_core.documents import Document
from langchain_text_splitters import MarkdownHeaderTextSplitter, RecursiveCharacterTextSplitter

from rag.lang import normalize

HEADERS = [("#", "h1"), ("##", "h2"), ("###", "h3")]
SUFFIXES = {".md", ".txt", ".pdf"}


def read_file(path):
    if path.suffix.lower() == ".pdf":
        import pymupdf4llm
        return pymupdf4llm.to_markdown(str(path))   # sarlavhalar '#' ko'rinishida saqlanadi
    return path.read_text(encoding="utf-8")


def split(text, source, child_size=500, child_overlap=80):
    parents, children = {}, []
    child_splitter = RecursiveCharacterTextSplitter(chunk_size=child_size, chunk_overlap=child_overlap)
    for sec in MarkdownHeaderTextSplitter(HEADERS, strip_headers=False).split_text(normalize(text)):
        section = " > ".join(sec.metadata[key] for _, key in HEADERS if key in sec.metadata) or source
        pid = hashlib.sha1(f"{source}|{section}|{sec.page_content[:80]}".encode()).hexdigest()[:12]
        meta = {"source": source, "section": section, "parent_id": pid}
        parents[pid] = Document(page_content=sec.page_content, metadata=meta)
        for chunk in child_splitter.split_text(sec.page_content):
            children.append(Document(page_content=chunk, metadata=dict(meta)))
    return parents, children


def load_corpus(corpus_dir):
    parents, children = {}, []
    for path in sorted(Path(corpus_dir).rglob("*")):
        if path.suffix.lower() not in SUFFIXES:
            continue
        p, c = split(read_file(path), path.relative_to(corpus_dir).as_posix())
        parents |= p
        children += c
    return parents, children


def save_parents(parents, path):
    data = {pid: {"text": d.page_content, "metadata": d.metadata} for pid, d in parents.items()}
    Path(path).write_text(json.dumps(data, ensure_ascii=False, indent=1), encoding="utf-8")


def load_parents(path):
    data = json.loads(Path(path).read_text(encoding="utf-8"))
    return {pid: Document(page_content=v["text"], metadata=v["metadata"]) for pid, v in data.items()}
```

Random fake embeddings make hybrid ranking flaky: with RRF fusion, a random dense ranking can tie with the sparse one. This tiny bag-of-words embedding ranks by shared words, so dense and sparse agree and the tests are deterministic, with no model download.

```python
import math
import zlib

import pytest
from langchain_core.embeddings import Embeddings

from rag.lang import normalize


class BowEmbedding(Embeddings):
    """So'zlar xaltasi: umumiy so'zi ko'p matnlar yaqin. Faqat testlar uchun."""
    size = 128

    def _vec(self, text):
        v = [0.0] * self.size
        for w in normalize(text).lower().split():
            v[zlib.crc32(w.strip(".,?!").encode()) % self.size] += 1.0
        n = math.sqrt(sum(x * x for x in v)) or 1.0
        return [x / n for x in v]

    def embed_documents(self, texts):
        return [self._vec(t) for t in texts]

    def embed_query(self, text):
        return self._vec(text)


@pytest.fixture()
def bow():
    return BowEmbedding()
```

```python
"""Qdrant kolleksiyasi: har bir chunk uchun dense (bge-m3) va sparse (BM25) vektor bitta joyda."""
from langchain_huggingface import HuggingFaceEmbeddings
from langchain_qdrant import FastEmbedSparse, QdrantVectorStore, RetrievalMode

from rag.config import settings


def dense_embeddings():
    return HuggingFaceEmbeddings(model_name=settings.embed_model, encode_kwargs={"normalize_embeddings": True})


def sparse_embeddings():
    # O'zbek tili uchun inglizcha stemmer noto'g'ri qisqartiradi: o'chiriladi.
    return FastEmbedSparse(model_name="Qdrant/bm25", disable_stemmer=True)


def build(children, embedding, sparse_embedding, path=None, collection=settings.collection):
    where = {"path": str(path)} if path else {"location": ":memory:"}
    return QdrantVectorStore.from_documents(
        children, embedding=embedding, sparse_embedding=sparse_embedding, collection_name=collection,
        retrieval_mode=RetrievalMode.HYBRID, force_recreate=True, **where)


def store_for(client, mode, embedding, sparse_embedding, collection=settings.collection):
    """Bitta Qdrant client ustida boshqa qidiruv rejimi (local rejimda papkani faqat bitta client ochadi)."""
    return QdrantVectorStore(client=client, collection_name=collection, embedding=embedding,
                             sparse_embedding=sparse_embedding, retrieval_mode=mode)
```

```python
"""Cross-encoder reranker: savol va har bir chunkni birga o'qib, qayta tartiblaydi."""
from rag.config import settings


class Reranker:
    def __init__(self, model_name=settings.rerank_model):
        from sentence_transformers import CrossEncoder
        self.model = CrossEncoder(model_name, max_length=512)

    def rerank(self, query, docs, top_n):
        if not docs:
            return []
        scores = self.model.predict([(query, d.page_content) for d in docs])
        order = sorted(range(len(docs)), key=lambda i: -float(scores[i]))
        return [docs[i] for i in order[:top_n]]
```

```python
"""Uch qidiruv rejimi (ablation uchun) va child -> parent kengaytirish."""
from langchain_qdrant import RetrievalMode

from rag.config import settings
from rag.index import store_for
from rag.lang import normalize

MODES = ("dense", "hybrid", "hybrid_rerank")


class Retriever:
    def __init__(self, client, parents, embedding, sparse_embedding, reranker=None,
                 top_k=settings.top_k, top_n=settings.top_n, collection=settings.collection):
        self.parents, self.reranker, self.top_k, self.top_n = parents, reranker, top_k, top_n
        self.stores = {
            "dense": store_for(client, RetrievalMode.DENSE, embedding, sparse_embedding, collection),
            "hybrid": store_for(client, RetrievalMode.HYBRID, embedding, sparse_embedding, collection),
        }

    @classmethod
    def from_disk(cls, with_reranker=True):
        from qdrant_client import QdrantClient
        from rag.index import dense_embeddings, sparse_embeddings
        from rag.ingest import load_parents
        from rag.rerank import Reranker
        return cls(QdrantClient(path=str(settings.qdrant_path)), load_parents(settings.parents_path),
                   dense_embeddings(), sparse_embeddings(), Reranker() if with_reranker else None)

    def search(self, query, mode):
        if mode not in MODES:
            raise ValueError(f"Noma'lum rejim: {mode}. Mavjudlari: {', '.join(MODES)}")
        query = normalize(query)
        rerank = mode == "hybrid_rerank"
        store = self.stores["dense" if mode == "dense" else "hybrid"]
        hits = store.similarity_search(query, k=self.top_k if rerank else self.top_n)
        if rerank:
            hits = self.reranker.rerank(query, hits, self.top_n)
        return self._parents_of(hits)

    def _parents_of(self, hits):
        seen, out = set(), []
        for d in hits:
            pid = d.metadata["parent_id"]
            if pid not in seen:
                seen.add(pid)
                out.append(self.parents[pid])
        return out
```

```python
"""LLM'dan Pydantic obyekt olish: avval provayderning o'z JSON-schema rejimi, bo'lmasa matndagi JSON."""
import json
import re

from rag.llms import text_of


def ask_structured(llm, schema, messages):
    try:
        out = llm.with_structured_output(schema, method="json_schema").invoke(messages)
        if isinstance(out, schema):
            return out
    except (NotImplementedError, ValueError, TypeError):
        pass   # bu model json_schema rejimini qo'llamaydi: quyidagi usul
    hint = ("Faqat shu JSON sxemaga mos bitta JSON obyekt qaytar, boshqa matn yozma:\n"
            + json.dumps(schema.model_json_schema(), ensure_ascii=False))
    text = text_of(llm.invoke([*messages, ("user", hint)]))
    match = re.search(r"\{.*\}", text, re.S)
    if not match:
        raise ValueError(f"Javobda JSON topilmadi: {text[:200]!r}")
    return schema.model_validate_json(match.group(0))
```

```python
"""RAG pipeline'lari LangGraph grafi sifatida. Bitta builder: ablation'dagi har bir rejim shu yerdan."""
from typing import Literal, TypedDict

from langchain_core.documents import Document
from langgraph.graph import END, START, StateGraph
from pydantic import BaseModel

from rag import prompts
from rag.lang import detect_lang
from rag.llms import text_of
from rag.structured import ask_structured

PIPELINES = ("no_rag", "dense", "hybrid", "hybrid_rerank", "corrective")


class State(TypedDict, total=False):
    question: str
    query: str
    route: str
    docs: list[Document]
    rewrites: int
    answer: str
    sources: list[str]
    contexts: list[str]


class Route(BaseModel):
    route: Literal["retrieve", "direct"]


class Grades(BaseModel):
    relevant_ids: list[int]


class Rewrite(BaseModel):
    query: str


class Grounded(BaseModel):
    grounded: bool


def numbered(docs):
    return "\n\n".join(f"[{i}] ({d.metadata.get('source', '')}) {d.page_content}" for i, d in enumerate(docs, 1))


def build_graph(pipeline, generator, control=None, retriever=None, max_rewrites=2):
    if pipeline not in PIPELINES:
        raise ValueError(f"Noma'lum pipeline: {pipeline}. Mavjudlari: {', '.join(PIPELINES)}")
    mode = "hybrid_rerank" if pipeline == "corrective" else pipeline

    def direct(s):
        answer = text_of(generator.invoke([("system", prompts.ANSWER_DIRECT), ("user", s["question"])]))
        return {"answer": answer.strip(), "sources": [], "contexts": []}

    def retrieve(s):
        return {"docs": retriever.search(s.get("query") or s["question"], mode)}

    def generate(s):
        docs = s["docs"]
        system = prompts.ANSWER_WITH_CONTEXT.format(context=numbered(docs))
        answer = text_of(generator.invoke([("system", system), ("user", s["question"])]))
        return {"answer": answer.strip(), "sources": [d.metadata.get("source", "") for d in docs],
                "contexts": [d.page_content for d in docs]}

    def route(s):
        r = ask_structured(control, Route, [("user", prompts.ROUTE.format(question=s["question"]))])
        return {"route": r.route, "rewrites": 0}

    def grade(s):
        docs = s["docs"]
        g = ask_structured(control, Grades, [("user", prompts.GRADE.format(question=s["question"], docs=numbered(docs)))])
        return {"docs": [docs[i - 1] for i in g.relevant_ids if 1 <= i <= len(docs)]}

    def rewrite(s):
        r = ask_structured(control, Rewrite, [("user", prompts.REWRITE.format(
            question=s["question"], query=s.get("query") or s["question"]))])
        return {"query": r.query, "rewrites": s.get("rewrites", 0) + 1}

    def check(s):
        g = ask_structured(control, Grounded, [("user", prompts.GROUNDED.format(
            context=numbered(s["docs"]), answer=s["answer"]))])
        return {} if g.grounded else unknown(s)

    def unknown(s):
        return {"answer": prompts.UNKNOWN[detect_lang(s["question"])], "sources": [], "contexts": []}

    def after_grade(s):
        if s["docs"]:
            return "generate"
        return "rewrite" if s.get("rewrites", 0) < max_rewrites else "unknown"

    g = StateGraph(State)
    if pipeline == "no_rag":
        g.add_node("direct", direct)
        g.add_edge(START, "direct")
        g.add_edge("direct", END)
    elif pipeline != "corrective":
        g.add_node("retrieve", retrieve)
        g.add_node("generate", generate)
        g.add_edge(START, "retrieve")
        g.add_edge("retrieve", "generate")
        g.add_edge("generate", END)
    else:
        for name, fn in [("route", route), ("direct", direct), ("retrieve", retrieve), ("grade", grade),
                         ("rewrite", rewrite), ("generate", generate), ("check", check), ("unknown", unknown)]:
            g.add_node(name, fn)
        g.add_edge(START, "route")
        g.add_conditional_edges("route", lambda s: s["route"], {"retrieve": "retrieve", "direct": "direct"})
        g.add_edge("retrieve", "grade")
        g.add_conditional_edges("grade", after_grade, ["generate", "rewrite", "unknown"])
        g.add_edge("rewrite", "retrieve")
        g.add_edge("generate", "check")
        g.add_edge("check", END)
        g.add_edge("direct", END)
        g.add_edge("unknown", END)
    return g.compile()
```

```python
"""Bitta savolga javob: grafni yig'adi va LangSmith'ga metadata bilan yuboradi.

Ishga tushirish:  python -m rag.ask "Tokenizer nima?" --pipeline corrective --generator ustoz-1.5b
"""
import argparse
import json
from functools import lru_cache

from rag.config import settings
from rag.graph import PIPELINES, build_graph
from rag.llms import get_llm, resolve


def run_config(pipeline, generator_name):
    _, model_id = resolve(generator_name)
    return {"run_name": f"ustoz-{pipeline}", "tags": [pipeline, generator_name],
            "metadata": {"pipeline": pipeline, "generator": generator_name, "model_id": model_id}}


@lru_cache(maxsize=1)
def retriever():
    from rag.retrieve import Retriever
    return Retriever.from_disk()


@lru_cache(maxsize=32)
def graph_for(pipeline, generator_name):
    needs_retrieval = pipeline != "no_rag"
    control = get_llm(settings.control_model) if pipeline == "corrective" else None
    return build_graph(pipeline, get_llm(generator_name), control=control,
                       retriever=retriever() if needs_retrieval else None, max_rewrites=settings.max_rewrites)


def ask(question, pipeline="corrective", generator_name="claude"):
    out = graph_for(pipeline, generator_name).invoke({"question": question},
                                                     config=run_config(pipeline, generator_name))
    return {k: out.get(k) for k in ("answer", "sources", "contexts", "route", "rewrites")}


def main():
    p = argparse.ArgumentParser()
    p.add_argument("question")
    p.add_argument("--pipeline", default="corrective", choices=PIPELINES)
    p.add_argument("--generator", default="claude")
    args = p.parse_args()
    out = ask(args.question, args.pipeline, args.generator)
    print(json.dumps({k: out[k] for k in ("answer", "sources", "route", "rewrites")}, ensure_ascii=False, indent=2))


if __name__ == "__main__":
    main()
```

```python
"""
import json
from collections import Counter
from pathlib import Path

HERE = Path(__file__).parent
FIELDS = {"id", "question", "answer", "source", "lang"}
UNKNOWN = {"Bilmayman.", "I don't know."}


def validate_rows(rows, eval_files):
    problems = []
    for id_, n in Counter(r.get("id") for r in rows).items():
        if n > 1:
            problems.append(f"{id_}: id {n} marta takrorlangan")
    for r in rows:
        rid = r.get("id")
        if set(r) != FIELDS:
            problems.append(f"{rid}: maydonlar {sorted(r)} — kerak {sorted(FIELDS)}")
            continue
        if r["lang"] not in {"uz", "en"}:
            problems.append(f"{rid}: lang '{r['lang']}' (uz yoki en bo'lishi kerak)")
        if r["source"] is None and r["answer"] not in UNKNOWN:
            problems.append(f"{rid}: manbasiz savolning javobi 'Bilmayman.' yoki \"I don't know.\" bo'lishi kerak")
        if r["source"] is not None and r["source"] not in eval_files:
            problems.append(f"{rid}: manba {r['source']} eval_files ichida emas")
    return problems


def main():
    rows = [json.loads(l) for l in (HERE / "rag_eval_set.jsonl").read_text(encoding="utf-8").splitlines() if l.strip()]
    eval_files = json.loads((HERE / "split.json").read_text(encoding="utf-8"))["eval_files"]
    problems = validate_rows(rows, eval_files)
    print("\n".join(problems) or f"OK: {len(rows)} ta savol")
    raise SystemExit(1 if problems else 0)
```

```python
"""LangSmith evaluator'lari. Qidiruv metrikalari aniq hisoblanadi; to'g'rilik va kontekstga sodiqlikni judge LLM baholaydi."""
from functools import lru_cache

from pydantic import BaseModel

from rag.config import settings
from rag.lang import detect_lang
from rag.llms import get_llm
from rag.structured import ask_structured


def _rank(outputs, reference_outputs):
    sources = outputs.get("sources") or []
    gold = reference_outputs["source"]
    return sources.index(gold) + 1 if gold in sources else None


def hit_at_5(inputs, outputs, reference_outputs):
    if reference_outputs["source"] is None:
        return {"key": "hit_at_5", "score": None}
    rank = _rank(outputs, reference_outputs)
    return {"key": "hit_at_5", "score": int(rank is not None and rank <= 5)}


def mrr(inputs, outputs, reference_outputs):
    if reference_outputs["source"] is None:
        return {"key": "mrr", "score": None}
    rank = _rank(outputs, reference_outputs)
    return {"key": "mrr", "score": 1 / rank if rank else 0}


def language_ok(inputs, outputs, reference_outputs):
    return {"key": "language_ok", "score": int(detect_lang(outputs["answer"]) == reference_outputs["lang"])}


class Verdict(BaseModel):
    reason: str
    ok: bool


@lru_cache(maxsize=1)
def judge():
    return get_llm(settings.judge_model)


CORRECT = """Talabaning savoliga berilgan javobni namuna javob bilan solishtir.
Javob namunadagi asosiy ma'noni to'g'ri bersa va unga zid fakt bo'lmasa ok=true. Uslub va uzunlik muhim emas.
Namuna "Bilmayman." / "I don't know." bo'lsa, faqat javob ham bilmasligini aytsa ok=true.
Savol: {q}
Namuna: {ref}
Javob: {ans}"""

FAITHFUL = """Javobdagi har bir fakt quyidagi kontekstda bormi? Hammasi bo'lsa ok=true.
"Bilmayman." / "I don't know." javobi ok=true.
Kontekst:
{ctx}
Javob: {ans}"""


def correct(inputs, outputs, reference_outputs):
    v = ask_structured(judge(), Verdict, [("user", CORRECT.format(
        q=inputs["question"], ref=reference_outputs["answer"], ans=outputs["answer"]))])
    return {"key": "correct", "score": int(v.ok), "comment": v.reason}


def faithful(inputs, outputs, reference_outputs):
    v = ask_structured(judge(), Verdict, [("user", FAITHFUL.format(
        ctx="\n\n".join(outputs.get("contexts") or []), ans=outputs["answer"]))])
    return {"key": "faithful", "score": int(v.ok), "comment": v.reason}


RETRIEVAL_EVALUATORS = [hit_at_5, mrr]
ANSWER_EVALUATORS = [language_ok, correct]
GROUNDING_EVALUATORS = [faithful]
```

```python
  python -m eval_rag.run_experiments --pipelines corrective --generators ustoz-1.5b,qwen-1.5b-instruct,groq,openai,claude

import argparse
import time
from pathlib import Path

from langsmith import Client

from eval_rag.evaluators import ANSWER_EVALUATORS, GROUNDING_EVALUATORS, RETRIEVAL_EVALUATORS
from eval_rag.upload_dataset import DATASET
from rag.ask import graph_for, run_config

OUT = Path(__file__).parent / "results"


def target_for(pipeline, generator):
    graph, config = graph_for(pipeline, generator), run_config(pipeline, generator)

    def target(inputs):
        start = time.perf_counter()
        out = graph.invoke({"question": inputs["question"]}, config=config)
        return {"answer": out["answer"], "sources": out.get("sources") or [],
                "contexts": out.get("contexts") or [], "latency_s": round(time.perf_counter() - start, 2)}
    return target


def main():
    p = argparse.ArgumentParser()
    p.add_argument("--pipelines", required=True)
    p.add_argument("--generators", required=True)
    p.add_argument("--limit", type=int)
    p.add_argument("--concurrency", type=int, default=2)
    args = p.parse_args()

    client = Client()
    data = list(client.list_examples(dataset_name=DATASET, limit=args.limit)) if args.limit else DATASET
    OUT.mkdir(exist_ok=True)
    for pipeline in args.pipelines.split(","):
        evaluators = ANSWER_EVALUATORS + ([] if pipeline == "no_rag" else RETRIEVAL_EVALUATORS + GROUNDING_EVALUATORS)
        for generator in args.generators.split(","):
            local = generator in {"ustoz-1.5b", "qwen-1.5b-instruct"}   # Ollama: bittadan
            results = client.evaluate(
                target_for(pipeline, generator), data=data, evaluators=evaluators,
                experiment_prefix=f"{pipeline}__{generator}",
                metadata=run_config(pipeline, generator)["metadata"],
                max_concurrency=1 if local else args.concurrency)
            path = OUT / f"{pipeline}__{generator}.csv"
            results.to_pandas().to_csv(path, index=False)
            print("Saqlandi:", path)


if __name__ == "__main__":
    main()
```

```python
"""eval_rag/results/*.csv -> results/rag_scores.md (ikki jadval: pipeline ablation va generatorlar).

"""
from pathlib import Path

import pandas as pd

HERE = Path(__file__).parent
OUT = HERE.parent / "results" / "rag_scores.md"
METRICS = [("hit_at_5", "Hit@5"), ("mrr", "MRR"), ("correct", "Correct"), ("faithful", "Faithful"),
           ("language_ok", "Right language"), ("latency_p50_s", "Latency p50 (s)")]
PIPELINE_ORDER = ["no_rag", "dense", "hybrid", "hybrid_rerank", "corrective"]


def summarize(df):
    s = {c.removeprefix("feedback."): df[c].dropna().mean() for c in df.columns if c.startswith("feedback.")}
    if "outputs.latency_s" in df:
        s["latency_p50_s"] = float(df["outputs.latency_s"].median())
    return s


def table(rows, first):
    head = f"| {first} | " + " | ".join(t for _, t in METRICS) + " |"
    lines = [head, "|" + "---|" * (len(METRICS) + 1)]
    for name, s in rows:
        cells = []
        for key, _ in METRICS:
            v = s.get(key)
            cells.append("—" if v is None or pd.isna(v) else (f"{v:.2f}" if key == "latency_p50_s" else f"{v:.0%}"))
        lines.append(f"| {name} | " + " | ".join(cells) + " |")
    return "\n".join(lines)


def main():
    runs = {p.stem: summarize(pd.read_csv(p)) for p in sorted((HERE / "results").glob("*.csv"))}
    ablation = [(p, runs[f"{p}__claude"]) for p in PIPELINE_ORDER if f"{p}__claude" in runs]
    generators = [(k.split("__")[1], s) for k, s in runs.items() if k.startswith("corrective__")]
    OUT.write_text("# RAG scores\n\nTest set: `eval_rag/rag_eval_set.jsonl` (LangSmith dataset `ustoz-rag-eval-v1`).\n\n"
                   "## Pipeline ablation (generator: Claude)\n\n" + table(ablation, "Pipeline") +
                   "\n\n## Generators (pipeline: corrective)\n\n" + table(generators, "Generator") + "\n",
                   encoding="utf-8")
    print(OUT.read_text(encoding="utf-8"))


if __name__ == "__main__":
    main()
```

```python
"""SFT v3 (RAFT): savol + kontekst (1 to'g'ri bo'lim, 2 chalg'ituvchi) -> manbali javob. Faqat train_files dan.

Ishga tushirish:  python -m sft_v3.build_raft      ->  sft_v3/train.jsonl, sft_v3/val.jsonl
"""
import json
import random
import re
from pathlib import Path

from pydantic import BaseModel

from rag.config import settings
from rag.graph import numbered
from rag.ingest import load_corpus
from rag.llms import get_llm
from rag.prompts import ANSWER_WITH_CONTEXT
from rag.structured import ask_structured

HERE = Path(__file__).parent
ROOT = HERE.parent
UNKNOWN_SHARE = 0.2
VAL_SHARE = 0.05

DRAFT = """Kurs materiali bo'limidan talaba beradigan 3 ta savol va 1-3 gapli to'g'ri javob yoz (o'zbek tilida, lotin).
Har bir javob oxiriga [1] qo'y (manba belgisi). Savollar faqat shu bo'lim bilan javob beriladigan bo'lsin.

{text}"""


class QA(BaseModel):
    question: str
    answer: str


class QAList(BaseModel):
    items: list[QA]


def make_example(question, answer, gold, distractors, rng):
    docs = list(distractors) + ([gold] if gold is not None else [])
    rng.shuffle(docs)
    if gold is None:
        reply = "Bilmayman."
    else:
        pos = docs.index(gold) + 1
        reply = re.sub(r"\[1\]", f"[{pos}]", answer)
    return {"task": "rag", "source": gold.metadata["source"] if gold is not None else None,
            "messages": [{"role": "system", "content": ANSWER_WITH_CONTEXT.format(context=numbered(docs))},
                         {"role": "user", "content": question},
                         {"role": "assistant", "content": reply}]}


def main():
    rng = random.Random(42)
    train_files = set(json.loads((ROOT / "eval_rag" / "split.json").read_text(encoding="utf-8"))["train_files"])
    parents, _ = load_corpus(settings.corpus_dir)
    pool = [p for p in parents.values() if p.metadata["source"] in train_files]
    llm = get_llm("claude")
    rows = []
    for gold in pool:
        others = [p for p in pool if p.metadata["source"] != gold.metadata["source"]]
        for qa in ask_structured(llm, QAList, [("user", DRAFT.format(text=gold.page_content))]).items:
            unknown = rng.random() < UNKNOWN_SHARE
            rows.append(make_example(qa.question, None if unknown else qa.answer, None if unknown else gold,
                                     rng.sample(others, 3 if unknown else 2), rng))
    rng.shuffle(rows)
    n_val = max(1, int(len(rows) * VAL_SHARE))
    for name, part in [("val.jsonl", rows[:n_val]), ("train.jsonl", rows[n_val:])]:
        (HERE / name).write_text("\n".join(json.dumps(r, ensure_ascii=False) for r in part) + "\n", encoding="utf-8")
    print(f"train {len(rows) - n_val}, val {n_val} -> {HERE}")


if __name__ == "__main__":
    main()
```

```python
"""Ustoz RAG demo serveri.

Ishga tushirish:  uvicorn rag.server:app --port 8473   ->   http://127.0.0.1:8473
"""
from pathlib import Path

from fastapi import FastAPI, HTTPException
from fastapi.responses import FileResponse
from pydantic import BaseModel

from rag.ask import ask
from rag.graph import PIPELINES
from rag.llms import REGISTRY, ModelConfigError, resolve

WEB = Path(__file__).parent / "web"
app = FastAPI(title="Ustoz RAG")


class AskRequest(BaseModel):
    question: str
    pipeline: str = "corrective"
    generator: str = "claude"


def available(name):
    try:
        resolve(name)
        return True
    except ModelConfigError:
        return False


@app.get("/")
def index():
    return FileResponse(WEB / "index.html")


@app.get("/api/options")
def options():
    return {"pipelines": list(PIPELINES), "generators": [{"id": n, "available": available(n)} for n in REGISTRY]}


@app.post("/api/ask")
def ask_endpoint(req: AskRequest):
    if not req.question.strip():
        raise HTTPException(400, "Savol bo'sh")
    if req.pipeline not in PIPELINES:
        raise HTTPException(400, f"Noma'lum pipeline: {req.pipeline}")
    if req.generator not in REGISTRY or not available(req.generator):
        raise HTTPException(400, f"Model mavjud emas yoki sozlanmagan: {req.generator}")
    out = ask(req.question.strip(), req.pipeline, req.generator)
    return {k: out[k] for k in ("answer", "sources", "route", "rewrites")}
```
